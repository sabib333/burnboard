# BURNBOARD — ProductHunt Launch Guide

## Tagline
**No AI. Just Humans Roasting Humans.** 🔥

## Description
BURNBOARD is the anonymous social media roast platform. Submit LinkedIn, GitHub, Twitter, or Instagram profiles and get brutally roasted by real humans. Features live leaderboards, roast battles, Instagram-style stories, reels, and a personalized feed algorithm.

## Maker Comment
Hey PH! 👋

I built BURNBOARD because every "roast me" tool out there uses AI. Where's the fun in that? 

BURNBOARD is 100% human-powered roasting. You submit a profile, real people write the burns, and the community votes on the best ones. It's anonymous, it's brutal, and it's hilarious.

**What makes it different:**
- 🔥 **100% Human** — Zero AI slop. Every roast is written by a real person.
- 🎯 **6 Platforms** — LinkedIn, GitHub, Twitter/X, Instagram, TikTok, YouTube
- ⚔️ **Roast Battles** — Head-to-head voted matches
- 📖 **Stories** — 24h expiring hot takes
- 🎬 **Reels** — Vertical snap-scroll through top roast targets
- 🏆 **Live Leaderboard** — Rankings update in real-time
- 🔒 **100% Anonymous** — No accounts required, just roast

**Tech stack:** React, Supabase (Realtime + Auth + DB), Vite, Tailwind CSS, PWA-ready.

Try it: Submit your own profile and see if you can survive the heat. 🌶️
